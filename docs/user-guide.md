# 使い方

Geemil Workbenchの操作・対応形式・制約。概要と起動方法は[README](../README.md)を参照。キー操作の一覧はアプリの「ヘルプ → キーボードショートカット」にある。

## はじめる

1. 起動画面か「ファイル → 新規プロジェクト」（Ctrl+N）で、名前と保存先を指定する。点群ファイルをウィンドウにドロップしても始められる（プロジェクトがなければ作成画面が開く）。
2. 「ファイル → 点群を取り込む…」（Ctrl+I）でE57・LAS・LAZを追加する。E57は`data3D`ごと、LAS/LAZはファイルごとに1スキャンになる。複数スキャンを含むE57は、ファイル名のフォルダーにまとめる。
3. 最近使ったプロジェクトは起動画面とファイルメニューから開ける。

プロジェクトはフォルダーごと持ち運べる。取り込んだ後は元ファイルを参照しない。長時間の処理はバックグラウンドで動き、キャンセルできる。処理中も点群を見回せる（表示は処理を始める前の状態）。複数ファイルの取り込みをキャンセルしても、完了したファイルは残る。

## 画面

上からメニューバー、ツールバー、選択中のツールのオプションバー。左にプロジェクトツリーとレイヤー（境界をドラッグして高さを変えられる）、下にステータスバー。ビューアー右下のXYZヘルパーはカメラの向きに連動する（X赤・Y緑・Z青）。

## カメラと表示

### カメラ操作（V）

| 操作 | 動作 |
| --- | --- |
| 左ドラッグ／右ドラッグ／ホイール | 回転／平行移動／ズーム |
| ダブルクリック | その点を回転中心にする |
| クリック | その点のスキャンをツリーで選ぶ |
| ホイールドラッグ／ホイールダブルクリック | 回転／回転中心の指定（どのツールでも使える） |
| 右ボタンを押しながらW/S・A/D・E/Q | 前後・左右・上下に移動（どのツールでも使える。Shiftで4倍、Ctrlで1/4の速さ。押している間はショートカットが働かない） |
| Ctrl+ホイール | 回転中心ごと前進・後退（回転中心を通り抜けられる） |

キーでの移動では回転中心も一緒に動き、1秒に回転中心までの距離だけ進む。ツリーのスキャンかフォルダーをダブルクリックすると、視線の向きを保ったまま全体が収まる位置へカメラが寄る。全体表示（F）と上面・正面・側面・等角（7・1・3・5）は表示メニューにある。

### 表示の設定

- **平行投影（O）**: 奥行きで大きさが変わらない。断面や平面図の確認に使う。範囲選択も平行投影の視線で判定する。
- **EDL（E）**: 陰影を強調する。
- **描画点数**: 既定200万点。ツールバーで変えられ、次回も引き継ぐ。
- **点サイズ**: ツールバーで変える。「適応」はPotreeのADAPTIVEと同じで、まばらな場所ほど点を大きく描く。Potreeで公開する前にノイズの見え方を確認できる（点サイズ2がPotreeのサイズ1に当たる）。
- **色**: 「RGB」「高さ」「スキャンごと」から選ぶ。「高さ」は色のないスキャンの形を読むのに、「スキャンごと」は位置合わせの確認に使う。

## プロジェクトツリー

- チェックで表示を切り替える。フォルダーのチェックは中のスキャンをまとめて切り替える。
- Ctrlで追加・解除、Shiftで範囲選択、Ctrl+Shiftで範囲を追加。
- ドラッグ＆ドロップで、選んだ項目をまとめてフォルダーへ移す。入れ子のフォルダーでは、カーソル位置で最も内側のフォルダーが移動先になる。
- 右クリックで新しいフォルダー・名前の変更・移動先・フォルダーの解除・これだけ表示・プロジェクトから外す・プロパティ。
- スキャンの名前も変えられる（右クリックかプロパティ）。書き出すE57のスキャン名と、スキャンごとのLAS/LAZのファイル名に使う。
- 複数のスキャンかフォルダーを選んで「スキャン名を一括変更…」を選ぶと、中のスキャンがフォルダー・変更前・変更後の表で並ぶ。変更後を入力したスキャンだけ名前が変わる。「表をコピー」でExcelなどに貼れ、Excelから変更後の列（または3列すべて）をコピーして、貼り始めるセルを選んでCtrl+Vすると下へ順に埋まる。
- 「プロジェクトから外す」は、選んだスキャンとフォルダーを中身ごと外す。元に戻すで戻せ、データは「履歴のクリーンアップ」まで残る。
- フォルダーに入れたり出したりしても、点の位置は変わらない。複数のフォルダーを選んで「フォルダーの解除」を選ぶと、入れ子のものも含めてまとめて解除する。
- プロパティでは点数・元ファイル・対応画像などを確認できる。

## 点の選択と移動

点は消さずに、別のレイヤーへ移す（既定の移動先は「削除」）。対象は表示中のスキャンの、表示中のレイヤーの点。画面に出ていない原解像度の点も判定する。

### 矩形選択（R）・多角形選択（P）

矩形は左ドラッグで描く。多角形は左クリックで頂点を足し、ダブルクリックかEnterで閉じる。Escで選択を解除する。オプションバーで対象と移動先のレイヤーを選び、「選択した点を移動」（Delete）を押す。

- **範囲内**: 選択範囲を通して見える点を移す。既定ではカメラ前方の無限遠までが対象（CloudCompareの分割と同じ）。「奥行きを制限」を有効にすると、範囲内で最も手前の点から指定した厚さまでに限る。点群の中を移動しながら、目の前のノイズを消すのに使う。
- **範囲外（切り出し）**: 選択範囲を通して見えない点をすべて移す。

移す予定の点は赤で表示する。描き終えた選択は、視点を変えても残る（描いたときのカメラで判定する）。オプションバーの「選択した視点に戻る」で、描いたときの視点に戻れる。

### 3Dボックス選択（B）

矢印で軸方向に、青い四角で水平面内に箱を動かす。輪で回転し、各面の取っ手で大きさを変える（反対側の面は固定される）。Escでドラッグ前に戻す。「箱の中をハイライトする」で、箱の中の点を黄色で示す。「箱の外を移動（切り出し）」「箱の中を移動」で、選んだレイヤーへ移す。

## 位置合わせ

どの方法でも元の点は書き換えず、スキャンかフォルダーの追加変換として持つ。フォルダーの変換は中のすべてのスキャンと対応画像に掛かるので、階ごとにフォルダーにまとめて合わせ、最後に建物全体を合わせる、という手順を取れる。

### 数値入力

スキャンかフォルダーのプロパティの「位置合わせ（追加変換）」で、平行移動量とXYZ回転角を入力する。入力中はその場でプレビューされ、「適用」で反映、「入力を戻す」で取り消す。

### 移動・回転（T）

選んだスキャンの器械点（スキャン位置）に取っ手を出す。器械点がないもの（LAS/LAZ、姿勢のないE57、フォルダー）では箱の中心に出す。

- 矢印で軸方向、青い四角で水平面内に平行移動する（高さは変わらない）。
- 輪をドラッグすると、取っ手を中心にその軸まわりで回転する。水平を出したスキャンをZの輪で回すと、器械点を保ったまま向きだけを合わせられる。
- 点をダブルクリックすると、取っ手（回転の中心）をその点へ移す。すでに合っている建物の角などに置いて回せば、その点を動かさずに向きを合わせられる。何もない所をダブルクリックすると元に戻る。
- ドラッグ中は移動量・角度を表示し、離すと1回の編集になる。Escでドラッグを取り消す。

### 位置合わせツール（A）

ツリーで選んだスキャンかフォルダーを、表示中の他のスキャンに合わせる。動かす側を橙、基準を青で表示する。結果は「適用」するまでプレビューで、他のツールに切り替えても残る。未適用のまま別の項目を選ぶと、適用するか破棄するかを確認する。

- **対応点**: 動かす側と基準で同じ場所をクリックして組にする。3組以上で「対応点で合わせる」を押すと、最小二乗で合わせ、組ごとの残差を表示する。
- **ICP**: 重なる部分の形状で合わせる。開始距離（既定0.5m）は残っているずれより大きくする。収束するたびに対応距離を半分にし、終了距離（既定0.02m）まで絞る。結果には最後の距離でのRMSと重なりの割合を表示する。狭い距離で対応点が足りなくなったら、手前の距離の結果を返す。重なりが10%未満なら注意を出す。
- **全体を最適化**: 1つずつ合わせた後の仕上げ。表示中のスキャンを、重なる部分がすべてそろうように同時に動かし、ループの端に残るずれを全体に振り分ける。ツリーで選んだスキャンを固定する（選んでいなければ最初のスキャン）。開始距離は既定0.1m、終了距離は既定0.02m、サンプル点数は1スキャン5万点。結果はそのまま1回の編集として適用する。

### 記録と一覧

適用した結果は、方法・RMS・重なり・日時などと一緒に記録する。ツリーの名前の後ろに、合わせ済みなら緑のチェック、記録の後に動かしたもの・ICPで絞りきれなかったもの・重なりが少ないものには注意の印を出す。マウスを載せると内容が出る。

「ツール → 位置合わせの一覧」では、全スキャン・フォルダーの状態と、直前の全体最適化での組ごとの重なりとRMSを表で見られる。行をクリックするとツリーで選ぶ。「CSVで保存…」でCSVに書き出せる。

### 練習用にスキャンをばらす

「ツール → 練習用 → 位置合わせ練習用にスキャンをばらす…」で、合わせ済みのデータを使って位置合わせを練習できる。全スキャンをZ軸まわりにランダムに回し、水平方向の中心を1か所に集め、床の高さをそろえる。現在の位置合わせは失われるが、元に戻すで戻せる。

## フィルター

ツールメニューから実行する。表示中のスキャンの、表示中のレイヤーの点を判定し、該当する点を別のレイヤーへ移す。点の位置・色・属性は書き換えない。パラメーターは次回も引き継ぐ。

| フィルター | 内容 | 既定の移動先 |
| --- | --- | --- |
| ボクセル間引き | ボクセルごとに、中心に最も近い1点を残す。「表示中のスキャンをまとめて間引く」を選ぶと、スキャンの重なりでも1ボクセル1点にする（書き出し前の仕上げ用） | 間引き |
| ノイズ除去 | 探索半径の中にある点が、最小近傍点数より少ない孤立点を移す | ノイズ |
| 統計的外れ値除去（SOR） | 近傍点までの平均距離が、全体の平均より標準偏差の指定倍以上大きい点を移す（既定はCloudCompareと同じ6点・1σ） | ノイズ |
| スキャンの重なりを整理 | 格子（既定10cm）ごとに、最も密に点を取っているスキャンの点だけを残す | 重複 |
| 動体除去 | 通行人など、一部のスキャンにだけ写った物を移す | 動体 |

**スキャンの重なりを整理**: 位置合わせ後に、重なる場所で複数スキャンの点が混ざってざらついて見えるのを防ぐ。近いスキャンや正面から撮ったスキャンほど密なので、そのスキャンが残る。スキャンの境目は、格子の階段状ではなく、密度が釣り合う線に沿う。器械点のないスキャンでも使える。

**動体除去**: 器械点から見た距離画像を作り、別のスキャンのレーザーが素通りした場所にある点を、そこに何もなかったとみなして移す。

- 素通りしたスキャンが指定数（既定2）以上ある点だけを移す。床の映り込みでできたゴーストや、1スキャンだけの位置合わせのずれを移しにくくするため。そのぶん、2スキャンからしか見えない場所の動体は残る。
- 密度によらないので、SORやノイズ除去では落とせない、密に写った人も移せる。
- 素通りを判定できるのは、器械点を持つスキャン（姿勢付きのE57）だけ。位置合わせを済ませてから実行する。
- 床下のゴーストは、先にボックス選択などで別のレイヤーへ移しておく（残っていると床を移すことがある）。
- 手すりや椅子の脚など細い物は移ることがあるので、移した点を確かめてから書き出す。

## レイヤー

すべての点は、どれか1つのレイヤーに属する。取り込んだ点は「点群」に入る。

- チェックを外したレイヤーの点は、表示・選択・処理・書き出しのどれにも使わない。
- 操作が新しく作るレイヤーは、非表示で始まる。
- 右クリックで名前の変更、「すべての点を移動」（例: 「ノイズ」を全部「点群」へ戻す）、削除（点は「点群」へ戻る）。
- 一部だけ戻すときは、そのレイヤーを表示し、範囲選択で移動先に「点群」を選ぶ。
- 「新しいレイヤー」で自分用のレイヤー（地面・建物など）を作れる。

## 編集履歴とリビジョン

- 元に戻す（Ctrl+Z）、やり直す（Ctrl+Y / Ctrl+Shift+Z）。
- 編集のたびに作業状態をプロジェクトへ書き込むので、異常終了しても続きから再開できる。
- 「ファイル → 保存」（Ctrl+S）で、作業状態を名前付きのリビジョンとして保存する。
- 「ファイル → リビジョン一覧」で、保存したリビジョンをgitのグラフのように表示し、開く・名前の変更・削除ができる。過去のリビジョンを開いて編集・保存すると、新しい枝になる。
- 「履歴のクリーンアップ」で、どのリビジョンからも使われていないデータを消してディスク容量を空ける。不要なリビジョンは先に一覧で削除しておく。元に戻す履歴は消える。

## 書き出し

未保存の変更を含む現在の状態の全スキャンから、表示中のレイヤーの点を書き出す。スキャンの表示チェックは対象を変えない。既存ファイルは上書きしない。

- **E57**: スキャンのposeにはフォルダーと自身の変換を合成し、対応画像にも同じ変換を掛ける。
- **LAS/LAZ**: 変換を適用した共通座標で、1つのファイルにまとめるか、スキャンごとに書き出す。座標の分解能は0.1mm。座標系（WKT）を持つスキャンはLAS 1.4、持たないものはLAS 1.2で書く。1つにまとめるときに属性の定義が違う場合は、「不一致の属性・付加情報を除いてまとめる」を選べる（除くものは事前に表示する）。すべての属性を残すには「スキャンごとに別のファイル」を選ぶ。

## 距離計測（M）

点を2つクリックすると、3D距離・水平距離・高低差を表示する。

## 対応形式

- **E57**: 元の数値属性を型ごとに保持する（RGB、強度、row/column、scaled integer、無効点を含む）。scan pose・image pose・画像・投影パラメーター・マスクも引き継ぐ。色のないスキャンは強度を灰色で表示する。
- **LAS/LAZ**: XYZ・強度・RGBに加え、分類・リターン・スキャン角・GPS時刻・NIR・Extra Bytesなどの属性と、VLR/EVLRを保持してLAS/LAZへ書き戻す。LAS固有の属性はE57へは書き出さない。波形パケット付きのファイルは取り込めない。

## 制約

- 座標単位はメートル前提。単位や座標参照系の変換はしない。座標メタデータの異なるスキャンを1つのファイルにまとめるとエラーにする。
- 未実装: 統合点群（間引いた結果を新しいスキャンとして保存）、画像からの再着色と画像の取り出し、LAS/LAZの波形パケット、処理の途中再開、複数リビジョンの集約。
- E57は、独自のXML構造を含むファイル全体の完全な再現は保証しない。元の点の順序は変わる。同じGUIDのファイルを重複して取り込んだ場合のGUID再割り当ては未対応。
- 開いているプロジェクトは、別のプロセスからは開けない（強制終了してもロックは自動で外れる）。
- キャンセルや失敗で残った一時データは自動では消えない。「履歴のクリーンアップ」で削除する。
- プロジェクトのディスク容量（元ファイルと同程度）に加え、取り込み中は一時的な作業容量が必要。
- プロジェクト形式は暫定版で、公開までは互換性を保証せずに変更する。
